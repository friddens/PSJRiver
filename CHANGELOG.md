## 0.1.0 – 2026-10-24

- Initial read-only JRiver MCWS PowerShell provider.
- Browse views and albums with `Set-Location` and `Get-ChildItem`.
- Read tracks with all MCWS metadata, including custom fields.
- Show track number, name, artist, album, duration and file key by default.
- Support credentials, configurable MCWS address and browse root, tab completion, wildcards and a short local cache.
- Support Windows PowerShell 5.1 and PowerShell 7.
- Include an interactive start script and optional live integration checks.
